# Osly

> Osly is an AI workflow automation platform from Alore AI that turns plain-English descriptions
> into running n8n-based automations, connecting 50+ SaaS applications. Osly publishes no
> developer portal, no API documentation and no OpenAPI. The only machine-readable description
> of its API is the company's own TypeScript SDK source in github.com/Osly-AI, which targets
> https://api.pocketflow.ai — the company's prior brand domain (pocketflow.ai redirects to
> osly.ai). As of 2026-08-14 every application and API host in the estate returns Cloudflare 522
> (origin unreachable); only the marketing site and the blog respond.

## API

- [PocketFlow SDK](https://github.com/Osly-AI/Pocketflow-SDK): First-party TypeScript SDK and
  `pocketflow` CLI. The only developer documentation the company publishes.
- Base URL: `https://api.pocketflow.ai` (currently HTTP 522)
- Auth: `X-API-Key` header, keys prefixed `pfl_`, issued from
  https://platform.pocketflow.ai/settings/api (redirects to app.osly.ai, HTTP 522)
- REST operations: `GET /workflows` (limit/offset/sort/order/search), `GET /workflows/{id}`
- Event surface: Socket.IO `run_workflow` emit; `run_start`, `stream_output`, `node_error`,
  `run_warning`, `run_complete`, `run_error`, `workflow_received`, `workflow_error`

## Open source
